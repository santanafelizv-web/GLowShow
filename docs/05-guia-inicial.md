# Guía rápida para empezar

1. Instala Android Studio.
2. Abre la carpeta `outputs/GlowShop`.
3. Si Android Studio pregunta por SDK o JDK, acepta instalar JDK 17 y Android SDK Platform 35.
4. Espera a que termine la preparación del proyecto. Luego pulsa el botón verde **Run ▶**.
5. Si aún no tienes teléfono conectado, elige crear un emulador Android.

La primera pantalla solo confirma que el proyecto abrió. El siguiente paso de desarrollo es conectar el inventario con la base local. Cuando aparezca un mensaje de error, copia aquí el texto o envía una captura y te indico qué hacer.
